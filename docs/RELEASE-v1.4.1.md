# v1.4.1 · 资源解析、原格式导出与项目备份修复

发布日期：2026-10-11

项目：[webmturn/ai-localization](https://github.com/webmturn/ai-localization)

版本：[v1.4.1](https://github.com/webmturn/ai-localization/releases/tag/v1.4.1)

本版完善「打开文件 → 批量翻译 → 逐条校对 → 导出」中的资源处理。结构化文件解析失败会显示原因，复数和分段可以分别校对，CSV、YAML 与文本可按原格式回写。项目 JSON 和数据备份携带原始文件与当前编辑，恢复后可继续校对和导出。

## 解析与校对显示

- 已知格式解析失败不再退回普通文本；同名文件失败导入时保留原文件与译文。
- CSV 自动识别常见表头及无表头数据，优先使用 source / original 列；YAML 支持多文档、真实路径与别名，循环引用明确报错。
- Android 禁译资源、RESX 非文本资源与废弃 Qt 消息不会进入翻译列表。
- PO / Qt 已存在的复数形态分别成为条目，XLIFF 保留分段身份；注释、引用和原始状态可展开查看。
- XML 内联标签显示为紧凑标记，保留完整资源内容；通用 XML 可提取短文本、CDATA 和常见可翻译属性。
- 文件编码、大小和格式开关统一作用于选择与拖放；旧编码可手动指定。
- 文本有自动、逐行与简单键值三种解析模式。默认自动模式仅识别明确的 `key=value`，正文冒号、逗号、URL 和反斜杠保留整行；编辑源文件继续使用文件保存的模式。

## 原格式导出

- CSV / TSV 按行列回写，保留额外列、表头、空行、未选中译文和行尾。
- YAML / YML 按文档和路径回写，保留数字、布尔值、空值、日期、数组位置与未选中内容；别名对应的不同资源可分别写入译文。
- TXT、无扩展名或实际按文本导入的文件保留原文件名；回写保留未选中行、注释、分隔符、引号、缩进、BOM 和各行行尾。
- 修正 JSON 根字符串、XML 同文异译、复数形态和 iOS Unicode 转义；PO / Qt 编码声明与下载的 UTF-8 内容一致。
- 单文件导出失败后继续处理其他文件，并显示失败文件及原因。原文、路径或行位置不匹配时明确失败，避免写入其他资源。

## 项目备份与自动保存

- 项目 JSON 与「偏好 → 数据管理」备份包含原始文件，不再只携带导出设备上的数据库引用。
- 备份使用当前内存中的译文与术语，保留尚未触发自动保存的编辑；完整备份无法读取项目或原文时显示失败原因。
- 自动保存确认原文成功写入后才移除内联副本。原文存储失败时保留副本，空间不足时报告失败，避免保存成缺少原文的项目。
- 保存期间继续编辑或切换项目时，待保存状态继续保留，后续编辑不会被旧快照误标为已保存。
- 重开项目时加载项目术语；没有打开项目时，全部备份仍保留独立术语库。带旧译文的待翻译资源完成编辑或校对后同步文件栏进度，示例项目也携带真实源文件。

## 使用与升级

发布附件 `ai-localization-v1.4.1-web.zip` 是已构建的网页版本。解压后打开 `public/index.html`，或将 `public/` 目录部署到静态服务器。无需重新安装 npm 依赖。`SHA256SUMS.txt` 提供压缩包校验值。

生产包在文件或本地服务器中正确使用生产模式；显式启用调试仍然有效。

从源码运行时，使用 Node.js 20.19+、22.12+ 或 24+，执行：

```bash
npm ci
npm run build
```

升级前可在「偏好 → 数据管理」备份项目与设置。旧项目中的既有译文继续兼容；旧备份从未保存的原始文件无法自动补回，先保留译文副本，再恢复对应原文件，避免同名导入覆盖校对。旧版 Windows 桌面预览安装包仍位于 v1.1.0 发布页；本次附件为网页版本。

## 格式范围

- YAML / YML 导出保留数据内容和结构，但会重新生成文本，不保留原注释、缩进、锚点名称或引用写法。CSV / TSV 字段引号写法可能规范化。
- 简单键值模式支持等号、冒号、Tab、逗号与续行，反斜杠转义按字面保留，不实现完整 INI / Java properties 语义。选中的续行会合并成一行，键值译文中的实际换行需先改为单行；逐行文本允许实际换行。
- 下载使用 UTF-8，不恢复旧字节编码。旧编码自动识别仍可能有歧义，可手动选择正确编码。
- 本版修复现有格式中已复现的问题，不宣称覆盖各格式标准的全部可选结构；未加入 Excel、Word 或 PDF 的专用资源导入。
