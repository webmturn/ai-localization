## 修正和交互

- 自动保存开关和间隔位于「偏好 → 数据管理」，修正此前错误的「外观设置」路径。
- 导出基于项目条目，搜索、状态筛选及分页不会限制范围；原格式按文件导出，缺少原始内容可能退回通用格式。
- 术语导入为 CSV / JSON，Excel 为术语导出选项；翻译资源解析不宣称支持 `.xlsx` 导入。
- 明确质量 PDF 使用打印窗口，记忆库目前没有 TMX 导入入口，项目 JSON 可能依赖本地原文件引用。
- 新增文件处理、质量规则、外观和 Prompt 设置入口；查找替换复用现有入口，无可处理文件时禁用并显示使用条件。
- 功能总览链接将焦点移到正文，桌面目录可独立滚动，手机可选择所有栏目；低高度横屏缩减目录周边内容，保证栏目可点击。
- 保留全文搜索、高亮、阅读位置、问答状态、设置草稿和关闭后的焦点恢复。

## 验证

- 45 个测试文件、690 项测试通过。帮助模块 28 项测试，包括分类导航、新增功能的搜索、设置入口、查找替换和空项目使用条件。
- 14 个隔离浏览器场景通过，无页面脚本异常；遍历全部功能总览分类与手机栏目，验证搜索、设置跳转、查找替换、记忆加载和阅读位置恢复。
- 检查 1440 × 1000、390 × 844、320 × 568、844 × 390，以及深浅主题和手机 18px 大字体。
- CSS、JavaScript 构建，状态所有权、全局函数冻结、diff 空白检查通过；全局检查仅保留已有重复挂载提示。
- 浏览器仅访问本地应用，外部请求被阻止，没有执行真实翻译、删除或文件写入操作。
