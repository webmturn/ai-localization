# 完整校对流程与项目备份验收

日期：2026-10-11。版本：v1.4.1。

## 复查结果

设置导航的按钮激活类、可见内容与计算样式在当前构建一致。等待颜色过渡结束后，浅色、深色下切换外观、文件、引擎、数据和质量设置均正确；即时截图可能保留切换中的旧颜色，没有据此修改导航代码。

以 CSV 24 条、PO 两个复数形态、TXT 两条、YAML 两条组成项目，在独立浏览器中完成实际文件选择、批量翻译按钮、译文输入、校对标记、筛选、分页和下载操作。翻译 API 请求由本地模拟响应拦截，未使用真实密钥或访问付费服务。

## 确认并修复的问题

- 手动保存、项目管理导出及数据管理备份仅携带本机原文缓存引用。现在下载包含原文、译文、状态、资源元数据、术语与项目配置；原文仅在缓存时等待取回，缺失时报告具体文件并建议先保存译文副本。
- 数据管理导出使用已保存副本，可能遗漏刚编辑的译文。现在优先固定当前编辑快照，全部备份替换同 ID 历史项目并加入尚未进入索引的新项目。
- 原文已有引用但写入失败时，自动保存可能删除唯一原文副本。现在对内存原文重试写入，仅成功后从持久化快照删除内联原文；空间不足不再以丢弃唯一副本换取保存成功。
- 保存等待期间继续编辑或切换项目，旧快照可能覆盖活跃项目标识或误清待保存状态。现在固定快照并记录编辑版本，存储写入前动态确认活跃项目，降级及文件夹备用保存遵循相同规则。
- 示例项目缺少原文。补齐与六条示例资源对应的 JSON 结构和路径，支持完整保存、重新解析及原格式导出。
- 已有模糊译文的待翻译资源在编辑、确认校对后没有刷新文件栏进度。现在按内容与完成状态更新进度，并保留当前文件的选中高亮，文件栏与校对条目一致。
- 术语可能在异步项目恢复前初始化，导致恢复项目中的术语未进入运行时；完整备份没有单独保存全局术语。现在恢复项目时显式加载术语（包含空数组），完整备份也保存独立术语快照。
- 生产包双击 HTML 或从本地服务器打开时，地址检测误开启开发模式。现在优先使用生产包标记，显式调试参数与本地调试设置仍可启用调试。

## 范围

旧备份若从未包含原文且原浏览器缓存已丢失，无法自动恢复原文件；先导出译文副本再恢复对应原文件。YAML 文本排版和注释、CSV 字段引号、旧字节编码的限制沿用格式修复说明。通用翻译交付 JSON 与可继续编辑的项目 JSON 用途不同。
